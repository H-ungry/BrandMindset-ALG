# 泛词识别业务口径笔记

> 2026-08-05 整理。为「词资产现状梳理」积累；全表数据不入仓（决策记录第 4 行），本笔记只记分类与口径。

## 词层五分类（课件四分法 + 8/5 内网文档校准出第五类）

| 词层 | 例子（脱敏示意） | 现有词表覆盖 |
| --- | --- | --- |
| 标准品牌词 | 品牌官方注册名 | 全覆盖 |
| 系列词 | 品牌下产品系列名 | 部分 |
| 品类关联词 | 品类词 + 品牌暗示组合 | 极少 |
| 产品特性词 | 功能/成分/卖点表达 | 几乎无 |
| 消费者昵称 | 社区黑话、缩写、错拼 | 无 |

## 识别现状（内网文档 + 找同学口询，8/5）

- 现在线上跑的是**规则词表**：只认标准品牌词与部分系列词，命中即算「品牌词搜索」。
- 泛表达（后三层）完全漏掉——这正是项目背景里「词口径不全」的量化主体。
- 模型侧：去年试过一版语义召回，没接线上，离线效果没复核过，这就是「模型准确率回测」任务的由来。

## 消费侧初步联想（给三家人）

- 统计口径：回搜指标现在只数标准词命中，泛词补进来后基数会变大，**指标口径要重定义**，找本人对齐。
- 报告呈现：分层展示 vs 合并展示，苏晴定。
- 链路成本：泛词识别若上线上模型，日志里要多埋一个「识别词层」字段，高远评估。
